# Local Markdown Clipper for Feishu & WeChat

一个本地运行的 Chrome 扩展，把当前浏览器中已经能够阅读的网页采集为 Markdown，并将可下载的正文图片一起打包为 ZIP。

扩展不会绕过登录或阅读权限，不使用飞书 API，也不会把采集内容上传到自有服务器。

## 支持范围

- 飞书文档：专用结构解析、自动滚动、图片本地化和基础 Markdown 格式。
- 微信公众号文章：正文识别、懒加载图片采集和重复图片处理。
- 生财有术课程页与文章详情页：独立页面适配。
- 普通图文网页：通过通用正文识别器采集；复杂站点可能需要手动选择区域。

## 安装

1. 下载并解压本项目，确保解压目录根部可以看到 `manifest.json`。
2. 在 Chrome 或 Chromium 中打开 `chrome://extensions`。
3. 开启右上角的“开发者模式”。
4. 点击“加载已解压的扩展程序”。
5. 选择包含 `manifest.json` 的整个项目目录。
6. 建议将扩展固定到浏览器工具栏。

扩展更新后，请在 `chrome://extensions` 中点击扩展卡片上的“重新加载”，并刷新准备采集的网页。

## 使用

1. 打开一个已经登录、有权阅读且正文可见的网页。
2. 点击浏览器工具栏中的扩展图标。
3. 在页面面板中点击“开始采集”。
4. 扩展会识别正文、回到正文顶部并自动向下滚动采集。
5. 采集完成后点击“下载 ZIP”。
6. 需要重新读取当前页面时，点击“重新采集”。

采集过程中可以使用“提前结束”保留当前结果，但导出的内容可能不完整。“关闭”只隐藏面板，不会中止当前采集；再次点击扩展图标可以恢复任务状态。

自动识别区域不理想时，可以展开“高级操作”，使用“手动选择区域”和“开始手动采集”。

## 导出结果

ZIP 文件名格式：

```text
文章标题__YYYYMMDD-HHmm.zip
```

解压后的内容类似：

```text
文章标题__YYYYMMDD-HHmm/
├── 文章标题.md
└── 文章标题.assets/
    ├── image-001.png
    └── image-002.jpg
```

成功下载的图片会改写为 Markdown 本地相对路径。图片因登录态、临时链接、防盗链或格式限制而下载失败时，扩展仍会生成 ZIP，并在 Markdown 中保留原始远程图片链接。

## 日志与排查

采集开始后可以随时点击“复制日志”。即使最终显示成功，也可能存在个别图片下载失败，复制日志可以帮助确认具体结果。

反馈问题时，建议提供：

- 网页类型和可公开的网址；私人页面不要公开链接。
- 问题发生在哪一步。
- 通过“复制日志”得到的运行日志。
- 导出结果中缺失或顺序异常的现象。

提交日志前请删除其中不希望公开的网址、标题或其他敏感信息，不要提交 Cookie、账号凭据或私人文档内容。

## 浏览器权限

- `activeTab`：只在用户点击扩展后访问当前标签页。
- `scripting`：把采集面板和解析模块注入当前页面。
- `downloads`：把生成的 ZIP 保存到浏览器下载目录。
- `<all_urls>`：支持不同网站正文和图片地址。扩展不会自动遍历浏览历史，只处理用户主动打开并启动采集的页面。

详细说明见 [PRIVACY.md](./PRIVACY.md)。

## 已知限制

- 只处理当前用户已经能够在浏览器中阅读的内容。
- 不进行 OCR、视频下载、云同步或 Obsidian 自动写入。
- 网页 DOM 结构变化后，站点适配器可能需要更新。
- 超长文档或大量大图可能增加浏览器内存占用和导出时间。
- 普通网页只能尽力识别正文，复杂布局不能保证完全还原。
- 浏览器内部页面，例如 `chrome://`，不允许扩展注入脚本。
